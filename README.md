# FPGA & Verilog Projects

Collection of FPGA and Verilog projects built while learning digital design.

## Hardware
- Shrike Lite FPGA
- Breadboards
- External LEDs

## Software
- Go Configure Hub v6.53 (I/O mapping, synthesizing & generating bitstream/.bin file)
- VS-Code (editing main.py[flashes the .bin onto FPGA])

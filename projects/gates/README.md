## Primitive Gates 

A simple Verilog FPGA system that takes user inputs to demonstrate the functioning of all primitive logic gates

## Features

- GPIO pins in input/high impedance mode
- Multiple  gates implemented using 3-Bit select lines to select individual gates

## Hardware Used

- Shrike Lite FPGA
- Breadboard + Power_Supply
- White LED

In the future:
- DIP switches for select lines and input signals

## Pinouts

- Select Lines:
        S0: F8
        S1: F10
        S2: F12

- Input Signals:
        A: F18
        B: F17

- Output:
        Y: F0

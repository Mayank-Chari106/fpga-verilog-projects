# RGB LED Controller

A simple Verilog FPGA project that changes RGB LED colours using clock division.

## Features
- RGB colour cycling
- Common-anode LED support
- FPGA GPIO control

## Hardware Used
- Shrike Lite FPGA
- External RGB LED
- Breadboard
